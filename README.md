# VOLT V/01

An independent interactive electric bicycle design concept by BlackStack Studio. Static HTML, CSS and locally bundled Three.js. Serve the directory with a static HTTP server. No installation, backend or third party runtime requests are needed.

Explore the native scroll assembly, choose frame finish, switch views and lights, change the disclosed illustrative assistance estimate, and download a configuration. This is a fictional product study. No orders or personal data are sent.

The original geometry and interface are project source. Dependency and font licences are in assets. All site paths are relative for GitHub Pages.

## iPhone Safari composition, October2026

The mobile experience now reserves explicit photographic or live-model frames in normal document flow. It does not move the hero object into arbitrary gaps between text blocks. Header, content, forms and footer share the mobile reading grid; desktop retains its cinematic composition. Exact local static font weights avoid variable-default differences across browser engines. Relevant touch interactions, portrait/landscape transitions and live scene visibility were checked in Playwright WebKit. This is browser emulation, not a physical iPhone test.
